Registro moderador

Ficha digital de consulta

Sentido histórico documentado

Abertura o cierre regulable de un horno que distribuye y gradúa el paso del calor entre compartimientos.

Variantes y control terminológico

La fuente usa registro para graduar el calor; moderador expresa la función inequívoca del dispositivo.

Autores y obras

P. C. Espinosa (1859).

Siglos representados

Siglo XIX

Temas de consulta

Citas clave

“r es el registro para graduar el calor.”

P. C. Espinosa · 1859
Construcciones de albañilería, horno para cocer cal y yeso, p. 50 del facsímil.

Lectura comparada

Espinosa describe registros que se abren y cierran para repartir el calor y precisa uno destinado expresamente a graduarlo.

Utilidad para investigación

Permite comprender el control térmico de hornos compartimentados y distinguir el registro de inspección del registro regulador.
