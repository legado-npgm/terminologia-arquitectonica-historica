# Terminología Arquitectónica Histórica

**Repertorio vivo de voces documentadas en tratados y diccionarios históricos**

Investigación, compilación y estudio documental: **Nina Patricia García Méndez**.

Este repositorio contiene la primera edición digital pública del Repertorio Vivo. La interfaz está formada por archivos HTML, CSS y JavaScript estáticos, una página por término, índices alfabéticos, autores, siglos, temas, variantes y relaciones.

## Dirección del sitio

`https://legado-npgm.github.io/terminologia-arquitectonica-historica/`

## Contenido

- 29 páginas de término;
- buscador y filtros;
- índices por letras, autores, siglos y temas;
- datos públicos en JSON y CSV;
- PDF consolidado de fichas digitales breves;
- sitemap y robots.txt preparados para indexación;
- metadatos de citación.

## Autoridad académica

Las fichas digitales derivan de registros académicos autorizados. La Ficha Madre conserva la autoridad documental y no forma parte de este repositorio público.
